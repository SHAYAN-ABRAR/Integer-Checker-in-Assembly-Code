# Integer-Checker

This is a basic **x86 Assembly Language** program that takes a signed integer as input from the user and prints whether it's **Positive** or **Negative**, using **signed conditional jump (`JS`)** logic.

---

## 💡 Features

- Takes a single-digit signed integer (like `-5` or `3`)
- Identifies whether it’s **Positive** or **Negative**
- Uses **`JS` (Jump if Sign)** for conditional logic
